# Prindle biopixel device files

`prindle.dwg` and `prindle.dxf` were provided by Gonzalo Vidal to Mike Arpaia for inclusion and redistribution in this DRAGGON Lab project. DRAGGON Lab is Gonzalo Vidal's research group at the University of Bristol.

The files preserve the source drawing and its DXF export. The DXF is the machine-readable input used by the microfluidics tutorial; scientific unit and geometry interpretations are documented and tested with the tutorial rather than asserted by these source artifacts.
